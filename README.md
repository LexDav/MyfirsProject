# LegalTech ТН ВЭД Bot (MVP)

Этот репозиторий содержит минимальный рабочий прототип Telegram-бота для классификации ТН ВЭД.

## Быстрый старт

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Задайте токен Telegram-бота:

```bash
export BOT_TOKEN="ваш_токен"
```

3. Запустите бота:

```bash
python -m app.bot
```

## Монолитный файл

Если нужен единый файл, используйте `bot_monolith.py`:

```bash
python bot_monolith.py
```

## Функциональность

- Поддержка режимов Light и Expert.
- Опросник в Light-режиме с фиксированными вопросами.
- Проверка кода через команду `/check <код>`.
- История запросов `/history`.

## Примечания

- Прототип использует простую эвристику на основе ключевых слов.
- Данные сохраняются в SQLite по умолчанию (`bot.db`).
